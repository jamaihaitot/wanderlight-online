# Operator Contract

## Overview

Defines the requirements and expected behaviors for operator observability and control in Wanderlight Online.

## Requirements

- Telemetry: connected players, join time, update latency, errors
- Structured logs for all key events
- World reset command for testing
- Error context in logs

## Acceptance Criteria

- Operator can view real-time metrics and logs
- Operator can reset world state
- Logs provide sufficient error context
